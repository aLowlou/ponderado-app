\# 📊 Ponderado — Calculadora de Promedios Académicos



Una aplicación web moderna y minimalista diseñada para estudiantes universitarios. Permite calcular promedios ponderados, simular escenarios con notas pendientes, gestionar exámenes sustitutorios y sincronizar datos en la nube de forma segura.



\## ✨ Características Principales



\*   \*\*Cálculo Dinámico:\*\* Soporte para múltiples trabajos con porcentajes de peso personalizables y opción para descartar la nota más baja.

\*   \*\*Simulador de Notas:\*\* Calcula automáticamente la nota exacta que necesitas obtener en lo pendiente para aprobar tu curso.

\*   \*\*Gestión de Sustitutorios:\*\* Simula el impacto de un examen sustitutorio reemplazando de forma inteligente tu promedio más bajo.

\*   \*\*Autenticación en la Nube:\*\* Inicio de sesión seguro mediante Google o correo electrónico gracias a Firebase Auth y Firestore.

\*   \*\*Enlaces para Compartir:\*\* Genera enlaces públicos en "Modo de solo lectura" para compartir tus notas con compañeros.



\## 🛠️ Tecnologías Utilizadas



\*   \*\*Frontend:\*\* HTML5, CSS3, JavaScript (Vanilla, orientado a componentes dinámicos).

\*   \*\*Estilos:\*\* Diseño oscuro personalizado con variables CSS, gradientes y tipografías de Google Fonts (\*Outfit\* e \*Inter\*).

\*   \*\*Backend \& Base de Datos:\*\* Firebase (Authentication \& Cloud Firestore).

\*   \*\*Hosting \& Despliegue:\*\* Vercel (CI/CD automático desde GitHub).
